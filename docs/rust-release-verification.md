# kax 1.0.0 릴리스 후보 검증

2026-11-24에 Python·Swift 기준 커밋 `e0127d0`과 Rust 후보를 대조했다. 인수 범위는 [Rust 재작성 요구사항](rust-rewrite-requirements.md)을 따른다.

## 자동 검증

| 항목 | 확인한 결과 |
|---|---|
| 단위·회귀 테스트 | macOS와 Windows에서 각각 113개 통과, 실패 0개. Apple Silicon에서 Intel용 테스트도 Rosetta로 실행해 113개가 통과했다. 기본 실행에서 제외되는 1개는 프로세스 잠금 테스트가 자식 프로세스에서 호출하는 도우미다. |
| 기준 테스트 103개 | 같은 이름의 Rust 테스트 76개와 별도의 동작 검증 22개가 대응한다. 5개는 지원이 종료된 Python 스킬 진입점 전용이다. |
| CLI·MCP 호환 | 양 OS의 도구 13개 스키마를 각 플랫폼의 기존 서버와 대조했다. CLI 오류 종류·종료 코드와 Mac MCP의 추가 인자, 미등록 도구, 정수의 소수·지수 표기를 검사했다. |
| 전송 저널 이전 | Python판의 확정·미확정 기록을 이전한 뒤 다시 이전해도 추가 복사된 기록이 0개였다. 미확정 전송 ID를 재호출해도 전송 호출은 0회였고 다른 대상이나 본문에 같은 ID를 쓰면 거부됐다. |

## 실기기

- **macOS** — Mac Studio M5 Max, macOS 27.0 빌드 26A425, 카카오톡 26.10.0. 채팅 목록에서 숨긴 자기방을 공식 프로필의 ‘나와의 채팅’으로 열어 확인했다. CLI에서 식별 메시지를 한 번 보낸 뒤 stdio MCP로 같은 전송 ID를 재호출했다. 첫 호출은 `nativeSendCalls=1`, 재호출은 `0`이었고 대화창에는 메시지가 정확히 한 건 남았다. CLI와 MCP의 앱 검색에서도 해당 문구가 각각 한 건 발견됐다.
- **Mac 이미지 읽기** — 사용자가 다운로드 폴더 접근을 허용한 뒤 대기 중이던 사분면 테스트 이미지 한 장이 자기방에 도착했다. CLI와 MCP가 반환한 388×268 PNG는 바이트 단위로 같았다. 원본과 네 사분면의 중심 픽셀을 비교한 결과 RGB 채널 차이는 최대 1/255였다. 검사 전후 입력창은 비어 있었고 클립보드의 내용 지문도 같았다.
- **Windows** — AZW SER8, Windows 11 Home x64 빌드 26200. CLI와 MCP를 실행하고 자기채팅을 찾아 열어 읽기·검색을 확인했다. 선택한 이미지 행의 PNG는 OCR을 켜고 꺼도 같은 해시였고, 두 경우 모두 스크롤 위치가 복원됐다. 같은 전송 ID를 재호출한 뒤 `nativeSendCalls=0`이었고 해당 메시지는 대화창에 정확히 한 건 남았다.

## 배포 검증

macOS Universal 바이너리는 Apple Silicon Mac에서 `arm64`와 `x86_64`로 각각 실행해 `kax 1.0.0`을 확인했다. Windows 실행 파일의 PE machine 값은 `0x8664`다. 두 배포 압축 파일의 SHA-256을 검증했고, 각각을 풀었을 때 실기기 검증용 실행 파일과 바이트 단위로 일치했다.

| 후보 실행 파일 | SHA-256 |
|---|---|
| macOS Universal `kax` | `ba4ebd327e4675ce50ac4b35ddb5ad5b03a409a428ebbe17e854f3d282adf254` |
| Windows x64 `kax.exe` | `b0da70d4bc600f320ff589bfbc312e66d1a0665edd3cd2692a160b25c24d730e` |

설치 스크립트는 정상 패키지를 설치하고 체크섬이 다른 파일을 거부했다. 릴리스 워크플로의 정적 검사와 버전 변경 후 Cargo.lock 검증을 수행했다. `cargo publish --dry-run --locked`에서 패키징과 재빌드가 성공했고, 이 패키지를 임시 경로에 `cargo install --locked`로 설치해 실행했다. GitHub Releases와 crates.io 공개 발행은 별도 작업이다.
